community radio

Retinue · field status

Radios that work when the towers do not.

Small LoRa radios relay encrypted messages device to device without cell towers, internet service, or a monthly bill. Three units are exchanging data on the workbench today. The next field target is a ten-site FIVCO pilot.

software in view

A few current surfaces from the same public repository family. Each profile names the working boundary, its state, and the projects around it.

Mere · platform · active

One graph model, carried between applications.

Mere gives Merely applications portable contracts for content, arrangement, memory, identity, and trusted exchange. Graphshell proves those projection contracts in a small reference host.

Read the project profile

Genet · platform · active

Web content as an embeddable engine.

Genet separates documents, layout, scripting, and realization so a host can take the browser profile it needs. Pelt is the thin reference browser that keeps those engine boundaries visible.

Read the project profile

Turnstone · product · prototype

Browse a web of things, not a stack of tabs.

Turnstone keeps pages, media, and notes as graph nodes that can be related, arranged, and opened together. Its current workbench is an early host for Mere and Genet rather than a finished browser shell.

Read the project profile

Woodshed · product · active

Practice material that knows how it relates.

Woodshed stages scales, chords, arpeggios, progressions, exercises, and sets through a typed musical graph. Related material remains visible while the musician chooses what to hear, draw, or practice next.

Read the project profile

Isometry · product · prototype

A tabletop that keeps the world around the board.

Isometry combines a pixel-art battlemap with campaign records, turn order, adjudication, and peer-to-peer play. The battlemap remains one projection of a larger shared tactical and historical account.
