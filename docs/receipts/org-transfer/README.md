# Organization-transfer receipts

One reviewed receipt belongs here for each repository transferred into the
`merely-made` organization.

The aggregate M1 publication-gate receipt is
[`2026-07-29_publication_gate.json`](2026-07-29_publication_gate.json).
Repository-specific transfer receipts are added only after a ready M1 gate
and explicitly authorized M2 transfer. Receipts record results and hashes,
never credential values or private machine paths.
