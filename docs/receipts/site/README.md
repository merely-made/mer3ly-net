# Site receipts

This directory holds human-sized acceptance evidence for the Mer3ly static
site, public repository authority, and optional repository graph.

`2026-07-29_repository_inventory.json` is generated by:

```powershell
./scripts/inventory-repositories.ps1
```

The inventory contains public GitHub metadata and workspace-relative checkout
locators. It must not contain credentials, private repository metadata, or
absolute machine paths.
